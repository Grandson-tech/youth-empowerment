# Favoured Youths Mentors Website

A modern, responsive website for Favoured Youths Mentors, a youth mentorship organization based in Narok, Kenya. The website is built using HTML, Tailwind CSS, and vanilla JavaScript.

## Features

- 🎨 Modern, clean design with a focus on user experience
- 📱 Fully responsive layout for all devices
- 🚀 Fast loading with optimized assets
- 🎯 Clear call-to-actions for donations and volunteer sign-ups
- 📊 Impact statistics and testimonials
- 🔍 Program filtering and categorization
- 📰 News/Blog section
- 📧 Newsletter subscription
- 🔗 Social media integration

## Pages

1. **Homepage (`index.html`)**
   - Hero section with main call-to-action
   - About Us preview
   - Programs overview
   - Impact statistics
   - Testimonials carousel
   - Volunteer sign-up form
   - News/Blog preview
   - Footer with contact info and newsletter

2. **Programs Page (`programs.html`)**
   - Program categories
   - Filterable program cards
   - Detailed program information
   - Call-to-action for program registration

## Technologies Used

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- Google Fonts (Poppins)
- Unsplash for placeholder images

## Design System

### Colors
- Primary: Teal (#1E9B8E)
- Secondary: Golden Amber (#F2A32A)
- Background: White (#FFFFFF)
- Text: Gray-800 (#333333)

### Typography
- Font Family: Poppins
- Weights: 300, 400, 500, 600, 700

### Components
- Rounded corners (8px+)
- Soft drop shadows
- Smooth hover transitions
- Mobile-first responsive breakpoints

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required - the site uses Tailwind CSS via CDN
